# Speravacuum Web

A modern, responsive HTML template designed for factory and industrial businesses. Built with Bootstrap, GSAP animations, and clean, professional design.

## Pages

- **Home** - Landing page with hero slider, services, and company highlights
- **About** - Company overview and history
- **Services** - Service listings with detail pages
- **Portfolio** - Project showcase with detail pages
- **Team** - Team member profiles with detail pages
- **Blog** - Blog listing with detail pages
- **Pricing** - Pricing plans and packages
- **FAQ** - Frequently asked questions
- **Appointment** - Booking and appointment form
- **Contact** - Contact information and form

## Tech Stack

- HTML5 / CSS3 / JavaScript
- Bootstrap 5
- GSAP (GreenSock Animation Platform)
- Swiper.js (Sliders)
- Font Awesome & Remix Icons
- Magnific Popup
- Odometer (Counters)
- SCSS (source files included)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Prathamesh-11-CEO/speravacuum-web.git
   ```

2. Open `industrie-ltr/index.html` in your browser.

No build step required — this is a static HTML template ready to use.
